# 📚 Library Manager — Электрондық кітапхана жүйесі

**Library Manager** — бұл Python тілінде жазылған, кітапхана қорын тиімді басқаруға, кітаптарды есепке алуға, іздеуге және олардың қолжетімділік статусын бақылауға арналған консольдік бағдарлама.

Жоба **«Алгоритмдеу және бағдарламалау негіздері»** пәні бойынша №7 мини-жоба ретінде орындалды.

---

## 🚀 Жобаның мүмкіндіктері

- 📖 **Кітаптар тізімін көру:** Базадағы барлық кітаптардың ID-нөмірін, атауын, авторын және статусын (Қолжетімді / Берілген) көрсету.
- ➕ **Жаңа кітап қосу:** Жүйеге жаңа кітаптың атауы мен авторын енгізу арқылы автоматты түрде ID тағайындау.
- 🔍 **Кітаптарды іздеу:** Атауы немесе авторы бойынша жылдам әрі ыңғайлы іздеу.
- 🔄 **Статусты өзгерту:** Кітаптың қолжетімділік күйін таңдау арқылы ауыстыру (бар / қолда жоқ).
- 🛡️ **Қателіктерді өңдеу:** Пайдаланушы қате сан немесе белгі енгізген жағдайда бағдарламаның тоқтап қалмауын қамтамасыз ету (`try-except`).

---

## 🛠️ Қолданылған технологиялар

- **Тіл:** Python 3.x
- **Деректер құрылымы:** Тізімдер (`list`), Сөздіктер (`dict`)
- **Басқару конструкциялары:** `while` циклі, `if-elif-else` шартты операторлары, функциялар (`def`)
